# ECO-177 — Input: migración al contrato de variante (tailwind-variants)

Strategy: design-system-quality

## Contexto

Input es raw-concat. Análisis previo (con el operador): **NO re-implementa ningún primitivo** (la caja del
input es lo propio de la pieza); **compone bien IconButton** (ojo de password) **+ SpinnerCircle** (loading).
Clasificación: **Simple** — su esencia es el CAMPO; el ojo/spinner son afordancias/helpers (como Button usa
SpinnerInfinity), no su estructura primaria. Va a `Simple/` aunque tenga `registryDependencies`.

## Alcance

- `Input.tsx`: la CAJA del input → contrato `tv` (`inputBox`, `twMerge:false`). Ejes: variant (default con
  outline / filled con relleno) × size (sm/md) × estado (error, disabled). El outline SOLO aplica a `default`
  (filled lo oculta) → `compoundVariants`. **API y píxeles idénticos.**
- Sigue componiendo **IconButton** (ojo) y **SpinnerCircle** (loading) — sin tocar (ya reusa bien).
- `inputSpecs` single-source de las clases reales; ComponentShowcase intacto.
- Story reorganizada en cajones (Variantes + Estados + Contenido + AllSizes + AllVariants) y movida a `Simple/`.

## No-goals / deuda anotada

- **Sin cambio visual** (fidelidad exigida).
- **Tamaño de icono NO se toca**: es una deuda TRANSVERSAL del sistema (el 16px mágico no propaga) → su propio
  ticket de foundation (escala de icono + componente `<Icon>`), no se parchea dentro de Input. El COLOR ya propaga.

## Acceptance Criteria

- La caja usa `tv`; API (`variant`/`size`/`error`/`loading`/`disabled`/`leftIcon`/`rightIcon`) intacta.
- Fidelidad: 16 combinaciones (variant × size × error × disabled) producen el MISMO conjunto de clases de la caja
  (`tests/input-fidelity.test.tsx`). Se retira al cerrar.
- registryDependencies conserva IconButton + SpinnerCircle; dashboard + satélite re-pullan sin drift.
- coverage + story-norm + composition-class + vitest + dashboard tsc verdes.

## Alignment

- **Pilar 1 (construcción):** migra Input al CONTRATO ÚNICO (`tv`), incl. estados por compoundVariants.
- **Pilar 4 (migración limpia):** censo-driven, tabla de fidelidad, sin cambio visual; la clasificación (Simple)
  se decide por juicio (esencia = campo), no por la mera presencia de deps.
