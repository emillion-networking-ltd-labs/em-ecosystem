# ECO-199 — Iconos de estado a fuente única `STATUS_ICONS` + gate (ampliación del sistema de iconos)

Strategy: design-system-quality

## Contexto

Al revisar el uso de iconos de **AlertBox** (antes de migrarla) saltó que el sistema de iconos (ECO-178/184/185/186)
estandarizó **tamaño + mecanismo** pero **NO el mapeo semántico** (qué icono por estado). Cada componente elegía el
suyo → **divergencia real**: el triángulo = `warning` en AlertBox pero `error` en Toast; Input usaba triángulo para
error. Es un hueco de **fuente única** de design-system-quality. Se cierra **ANTES** de migrar AlertBox, para que
aterrice ya sobre la fuente. (La migración es precisamente para barrer y dejar todo correcto.)

## Alcance

- **Fuente única** `design-system/lib/statusIcons.ts`:
  `STATUS_ICONS = { warning: TriangleAlert (⚠), error: CircleX (⊗), success: CircleCheck (✓), info: Info (ⓘ) }`
  — el set de AlertBox, el coherente (triángulo solo para warning; el resto círculos). En `lib/` para viajar con
  el cierre de em-ui. Set canónico fijado en **ADR-032**.
- **Alinear los 7 componentes de estado** a `STATUS_ICONS`: AlertBox, Toast (des-cambiar warning/error),
  InlineError, EmptyState, RateLimitBanner, Input (FormField delega en InlineError). Se elimina el `VARIANT_ICON`
  local de cada uno.
- **Gate `check-status-icons`** (required, en `coverage`): prohíbe importar un glyph de alerta a mano
  (`TriangleAlert`/`AlertTriangle`/`CircleAlert`/`CircleX`) → debe usar `STATUS_ICONS`.
- **Reconciliar** las copias em-ui (`lib/statusIcons.ts` se distribuye en el cierre a dashboard + satélite).

## No-goals

- NO tocar el TAMAÑO de icono (`ICON_SIZES` ya es fuente única; que Toast use `sm` por su compacidad es correcto).
- NO gatear `Info`/`CircleCheck` (usos genéricos fuera del semáforo de estado).
- NO migrar AlertBox a su DoD aquí (eso es el siguiente ticket, ya sobre la fuente única).

## Acceptance Criteria

- `lib/statusIcons.ts` es la fuente; los 7 componentes la usan; **ningún `VARIANT_ICON` local ni import de glyph
  de alerta** en un componente.
- `check-status-icons` corre en CI (`coverage`), verde; probado que caza un import de glyph de alerta a mano.
- Copias em-ui reconciliadas (`lib/statusIcons.ts` en dashboard + satélite); `governance`/drift verde.
- Suite (`vitest run`) + `coverage` verdes.

## Alignment

design-system-quality (ADR-029): el pilar de **fuente única** ("compón/usa la fuente única, no copies") aplicado a
los iconos de estado. **Amplía el sistema de iconos** (ECO-178/184, que fijó el TAMAÑO con `ICON_SIZES`) con la capa
**semántica** (`STATUS_ICONS`), ambas fuente única + gateadas. **ADR-032** fija el set canónico.
