# ECO-106 — Cosecha tanda 5 (Tier 3): CTAs de marketing + fondo (PulsatingButton, InteractiveHoverButton, Ripple)

Strategy: satellite-design

## Resumen
Quinta tanda de marketing (Fase 1) — el **Tier 3** de la shortlist: CTAs con efecto + un fondo. Tres piezas
Magic UI (MIT) integradas con el theming/escala del design-system:

- **PulsatingButton** — CTA que "respira" (overlay que late con `animate-pulse`). Reconstruido sobre el
  esquema de color del `Button` primary (`surface-inverse`/`content-inverse`, NO el accent); se omiten la
  variante `ripple` y el `useLayoutEffect` de sync `--bg` del original (innecesario con color por token).
- **InteractiveHoverButton** — CTA cuyo punto crece en hover y revela label + flecha. Verbatim salvo
  colores → tokens y flecha lucide `size-4`.
- **Ripple** — fondo de círculos concéntricos que laten. Verbatim salvo color crudo → token
  `content-primary`; el latido usa el keyframe `ripple` (`--animate-ripple`) añadido a `tokens.css` (append).

**Nota de scope:** `DotPattern` y `GridPattern` (también en la shortlist Tier 3) **ya existían** (ECO-86) con
color por token — no se duplican. Varios fondos ya estaban (Aurora, Meteors, Spotlight, Blob, GradientBackdrop).

## Acceptance Criteria
1. `PulsatingButton`, `InteractiveHoverButton`, `Ripple` en `components/`, grupo `Marketing/`, stories al
   estándar (inglés, Default → variantes; sin `layout:centered` para no recortar el fondo).
2. **Cero colores crudos** (los CTAs usan el color del `Button` primary, no el accent). El keyframe `ripple`
   vive en `tokens.css` (append, no altera tokens existentes).
3. **Cero dependencias npm nuevas** (`cn`/`lucide`/`motion` ya presentes). Atribución THIRD-PARTY-NOTICES (tanda 5).
4. Registry regenerado (cierre 5/5); `build-storybook` + `npm run coverage` verdes.
5. Aislamiento: solo `design-system/`; sin tocar api/dashboard ni el satélite. Dashboard-VRT verde.
6. Gates verdes (`Strategy: satellite-design`, ECO-106), Security Pipeline.

## Alignment
Pilar B (`satellite-design.md`): cierra la **cosecha gobernada** de marketing de la Fase 1 (CTAs + fondo) con
el patrón fijado — reconstruir controles con color sobre los tokens del sistema (el CTA usa el color del
`Button` primary, no inventa marca), color por tokens (cero crudos), cero deps nuevas, keyframes aditivos.
