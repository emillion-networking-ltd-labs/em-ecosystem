# ECO-185 — Rollout icono: barrido de hojas (glyphs directos a `<Icon>`)

Strategy: design-system-quality

## Contexto

Sexto paso del rollout del sistema de icono (ECO-178 core; 179 Input; 180 Avatar; 182 IconButton; 183 IconBadge;
184 escala regular). Los **contenedores** ya imponen el tamaño desde la escala. Faltan las **hojas**: ~15
componentes del DS que dibujan glyphs de lucide **directos con `size={N}` a mano** (número mágico), fuera de
cualquier contenedor.

## Alcance

Migrar cada render de glyph directo a `<Icon icon={Glyph} size="..." />` (import `./Icon`). Reconciliación por
tamaño (la escala PRESERVA el px → cero cambio visual salvo EmptyState):

- **16 → `md`**: Breadcrumbs, Calendar, Pagination, MetricCard, SearchTrigger, DateInput, InlineError,
  RecoveryCodesGrid, SidebarNav, LanguageSelector, AlertBox, RateLimitBanner.
- **14 → `sm`**: CopyField, Toast.
- **48 → `2xl` (40)**: EmptyState — único cambio visual, intencional (ECO-184 dropeó el 48; 2xl=40).

Detalles:
- **className de color** (`text-error`/`text-success`/…) → se conserva: `<Icon>` propaga `...props` al glyph.
- **`strokeWidth={2}`** (LanguageSelector) → default de lucide, redundante → se quita.
- **Alias local `Icon`** (AlertBox `const Icon = config.icon`; Toast `icon: Icon`; SidebarNav `const Icon`/
  `ChildIcon`; RateLimitBanner) → se renombra el local (choca con el componente `<Icon>`) y se usa `icon={Glyph}`.
- Cada hoja pasa a componer `Icon` (`registryDependencies += Icon`); siguen Simple. Re-pull a dashboard +
  satélite (byte-idéntico, sin drift). La API de las hojas NO cambia → sus consumidores no se tocan.

## No-goals

- El **gate anti-`size={N}`** en glyphs (forzar `<Icon>`) — ticket final del rollout, cuando ya no queden usos.
- Migrar hojas al contrato de variante (tv) — otra migración.

## Acceptance Criteria

- Ningún glyph de lucide se renderiza con `size={N}` a mano en `design-system/components/` (salvo dentro de la
  definición de `<Icon>` mismo). Todos vía `<Icon size="...">`.
- Tamaños preservados (16→md=16, 14→sm=14); EmptyState 48→2xl(40) documentado.
- `className` de color de cada glyph preservado.
- Copias distribuidas de las hojas afectadas sin drift.

## Alignment

Implementa **design-system-quality** (fuente única + sin números mágicos + propagación): elimina el último
reducto de tamaños de icono a mano (las hojas), dejando `ICON_SIZES` como única fuente para TODO icono del DS —
cambiar la escala re-dimensiona también las hojas sin tocarlas. Relacionado con [[eco-icon-size-system-debt]].
