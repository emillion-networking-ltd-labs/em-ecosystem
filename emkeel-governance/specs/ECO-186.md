# ECO-186 — Gate de icono: todo glyph de lucide vía `<Icon>` (cierra el rollout en el DS)

Strategy: design-system-quality

## Contexto

Cierre del rollout del sistema de icono (ECO-178..185). Con las hojas migradas, faltaba **fijar el invariante**:
que nadie vuelva a dibujar un icono a mano. El color de icono a mano YA está gateado (`check-raw-color` prohíbe
hex/paleta cruda fuera de tokens); el **tamaño/uso de icono no tenía gate**.

Un `check` por texto solo caza las formas que se le ocurre buscar. El barrido (ECO-185) buscaba `size={N}`
literal y se saltó tres disfraces de "icono a mano": el glyph partido en varias líneas (`<Check`↵`size={16}`), el
tamaño por variable o mapa local (`size={iconSizes[size]}`), y el tamaño por clase CSS (`className="size-4"`).

## Alcance

- **Gate `check-icon-usage.mjs`**: prohíbe renderizar un glyph de `lucide-react` **directo** (`<Search .../>`) en
  `components/` + `sections/`. Obliga a `<Icon icon={Glyph} size="..." />` (el contenedor impone el tamaño desde
  `ICON_SIZES`). No busca "size" — conoce los nombres importados de lucide y marca CUALQUIER `<Glyph>`, escrito
  como sea. Exento: `Icon.tsx` (define el render). Escape por línea: `icon-ok: <razón>`. Cableado en
  `npm run coverage`. Test de funciones puras + guard permanente (`tests/icon-usage.test.ts`).
- **Migrar los 6 stragglers que el gate destapó** (el barrido de texto no los vio):
  - Checkbox (Minus/Check, mapa local `{12,14,16}`) → `<Icon>` con `sm/md/lg = xs/sm/md` (12/14/16, exactos).
  - InteractiveHoverButton (`<ArrowRight className="size-4">`) → `<Icon size="md">` (16, exacto).
  - Contact (Check en círculo, 24) → `lg` (exacto).
  - Pricing / Services (check de bullet, 18 fuera de escala) → `md` (16) — reconciliación menor por juicio.
  - Testimonials (StarRating, `size` numérico 14/20) → prop `IconSize`: 14→`sm` (exacto), 20→`lg` (24, foco).
- Re-pull de los distribuidos afectados (Checkbox, InteractiveHoverButton) a dashboard + satélite; sin drift.

## No-goals

- **El código de features del dashboard** (71 glyphs a mano, fuera del DS) — su propio barrido; cuando se limpie,
  se añade `nexacore-dashboard/src` a las raíces del gate.

## Acceptance Criteria

- `check-icon-usage` pasa: 0 glyphs de lucide directos en `components/` + `sections/`.
- El gate está en `npm run coverage` y tiene test (funciones puras + guard del corpus).
- Los 6 stragglers renderizan vía `<Icon>`; tamaños exactos salvo Pricing/Services (18→16) y Testimonials
  (20→24), reconciliaciones menores documentadas.
- Copias distribuidas de Checkbox/InteractiveHoverButton sin drift.

## Alignment

Implementa **design-system-quality** (fuente única + propagación): el gate CONVIERTE el invariante "todo icono
desde la escala" en algo no-violable — grep-catchable en CI, escriban el tamaño como lo escriban. Cierra el
sistema de icono: `ICON_SIZES` es la única fuente y ya no se puede eludir. Relacionado con
[[eco-icon-size-system-debt]].
