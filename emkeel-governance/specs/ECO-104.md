# ECO-104 — Hero: stats con NumberTicker (animadas) + API HeroStat (value number + prefix/suffix)

Strategy: satellite-design

## Resumen
El `HeroStatCard` de la sección `Hero` renderizaba `stat.value` como texto estático. Ahora usa el
`NumberTicker` (cosechado en ECO-101) → las cifras **animan al entrar en vista**, más vivas. Para ello la
API de `HeroStat` cambia de `value: string` ("+500") a **`value: number`** + `prefix?`/`suffix?`/`decimals?`
(separa la cifra animable del adorno). El peso/tamaño no cambia (`text-h1 font-black`, ya coincidía con el
NumberTicker); el color se mantiene por contexto (`text-white` sobre media / `text-content-primary` en móvil).

## Decisiones / notas
- **Blast-radius mínimo:** el único consumidor del `<Hero stats>` del design-system es `Hero.stories.tsx`
  (catálogo). El satélite `sat-cristian-garcia` tiene su PROPIO `HeroStatCard` bespoke (no usa el Hero del DS),
  el dashboard no usa Hero → el cambio de API solo afecta al catálogo. Dashboard/Satellite-VRT lo confirman.
- **Server component intacto:** `Hero` sigue siendo server; `NumberTicker` entra como **client island**
  (anima al entrar en vista). El LCP es el titular (h1), no las stats.
- Registry: `Hero` (registry:section) gana dependencia interna a `NumberTicker` (closure regenerado).

## Acceptance Criteria
1. `HeroStat` = `{ value: number; prefix?; suffix?; decimals?; label }`; `HeroStatCard` renderiza
   `{prefix}<NumberTicker value decimalPlaces />{suffix}` con `text-h1 font-black` y el color por contexto.
2. `Hero.stories.tsx` actualizado a la nueva API (value numérico + prefix/suffix); las cifras animan.
3. Aislamiento: solo `design-system/` (sections/Hero.tsx + su story + registry regenerado); sin tocar
   api/dashboard ni el satélite; cero deps npm nuevas (NumberTicker ya en el DS). Dashboard-VRT + Satellite-VRT verdes.
4. `build-storybook` + `npm run coverage` + closure del registry verdes. Gates verdes (`Strategy: satellite-design`).

## Alignment
Pilar B (`satellite-design.md`): es la **composición gobernada** en acción — una sección del DS (Hero)
consume una pieza cosechada (NumberTicker) por su API, con tokens/escala/peso del sistema. Demuestra el uso
real de la cosecha (ECO-101) en una sección, no solo en su story.
