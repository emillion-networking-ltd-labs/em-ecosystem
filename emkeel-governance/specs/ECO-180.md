# ECO-180 — Avatar: User fallback a `<Icon>` (rollout icono, reconciliando tamaños)

Strategy: design-system-quality

## Contexto

Segundo paso del rollout del sistema de icono (ECO-178). Avatar dibujaba el User fallback con un mapa propio de
px FUERA de la escala (`{sm:14, md:18, lg:28}`). Se migra a `<Icon>` y se RECONCILIAN esos tamaños a los permitidos.

## Alcance

- El User fallback → `<Icon icon={User} size={...}>`. Reconciliación (manteniendo ~40% del diámetro del avatar):
  - Avatar sm (32px): 14 → **sm (14)** — exacto, sin cambio.
  - Avatar md (40px): 18 → **md (16)** — cambio menor (proporción 40%).
  - Avatar lg (64px): 28 → **xl (24)** — cambio menor (proporción 37.5%).
- Avatar pasa a componer `Icon` (registryDependencies += Icon); dashboard + satélite re-pullan el cierre sin drift.

## No-goals

- **Cambio visual menor e intencional** en el fallback (md/lg del avatar): 18→16, 28→24 — para usar SOLO tamaños
  de la escala. El fallback es un placeholder; la proporción se conserva.

## Acceptance Criteria

- El User fallback usa `<Icon>` con tamaños de la escala (sm/md/xl), sin px a pelo.
- `avatar-fidelity` (caja + clases) sigue verde; composition-class + tsc + anti-drift verdes.

## Alignment

- **Rollout del sistema de icono:** reconcilia una pieza con tamaños fuera de escala a los permitidos, por juicio
  (preservando la proporción), no copiando px arbitrarios. Relacionado con [[eco-icon-size-system-debt]].
