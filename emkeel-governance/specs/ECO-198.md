# ECO-198 — Accordion a DoD + mecanismo de completitud (Model B + check-piece-complete) (design-system-quality, Fase 1)

Strategy: design-system-quality

## Contexto

Llevar Accordion a done-done (el trigger del ticket) destapó que el DoD por-pieza estaba a medias y en un punto
incorrecto: la verificación de fidelidad de Accordion era la versión **DÉBIL** (comparaba un string de clases
inline, **sin fixture, sin render**) — la misma clase de hueco por el que una pieza salía "hecha" sin estarlo. Y
no había forma de **GARANTIZAR** que una pieza no se promocionara a medias. Como en ECO-197 (Badge fijó el DoD),
aquí **Accordion es el ejemplo trabajado que fija el MECANISMO**.

## Alcance

- **Colocación Model B en el catálogo:** las 53 piezas UI (primitives + simples + composite) pasan a `Migration/`
  (WIP); `Primitives/`/`Composite/` = estante **CERTIFICADO**. Una pieza se promociona (por su `@ds-role`) solo
  cuando pasa TODOS los pasos + la aprobación humana **[H]**.
- **DoD corregido** (`DEFINITION-OF-DONE.md`): **paso 8** = fidelidad AL ESTÁNDAR (fixture `<Name>Old` + render
  viejo-vs-nuevo + `old = new`) — es **TEST verídico, no una página**; **paso 7** = ORGANIZACIÓN por ejes (un
  bucket + overview por eje, sin mezclar); regla de colocación Model B.
- **Gate `check-piece-complete`** (required, keyed on placement): una pieza en `Primitives/`/`Composite/` DEBE
  tener evidencia máquina de **A** (contrato tv+Specs) / **B** (role) / **F** (fidelidad al estándar) / **Q**
  (a11y) / **C** (census) / **O** (un overview por cada eje ENUM), o **ROJO**. Promocionar a medias = imposible.
  `Migration/` exento (WIP). Idioma / norma-C / calidad de DISEÑO = [H].
- **Corpus Status** (`Foundations/Corpus Status`): dashboard por-paso de cada pieza (placement + A/B/F/a11y/O +
  ready), **misma fuente que el gate** (`census.mjs` reusa la lógica de `check-piece-complete`).
- **Accordion certificada** (el ejemplo): fixture `AccordionOld` + `accordion-fidelity` al estándar (35 casos) +
  `accordion-a11y` (axe + contrato disclosure) + a11y en el componente (`aria-expanded`/`aria-controls`/
  `role=region`/`aria-labelledby`/`type=button`) + stories reorganizadas en buckets (overviews `Surface`/
  `Indicator`, `AllVariants`=variant) + `Default` cerrado (base) + census → promocionada a `Primitives/Accordion`
  con [H].

## No-goals

- NO migrar el resto de piezas (van en tandas, cada una por el runbook); Accordion es el ejemplo.
- NO la página HTML temporal de fidelidad — el TEST verídico la garantiza; se descartó por decisión del operador.
- NO gatear los ejes booleanos/estado ni la calidad de DISEÑO (quedan en [H]); el gate cubre lo máquina-verificable.

## Acceptance Criteria

- `check-piece-complete` corre en CI (script `coverage`) y está **verde**: `Migration/` exento;
  `Primitives/`/`Composite/` exige A/B/F/Q/C/O; probado que bloquea una promoción incompleta.
- **Accordion en `Primitives/Accordion`**, certificada, con todos los pasos verdes; `accordion-fidelity` (35) +
  `accordion-a11y` verdes; fixture `AccordionOld` presente; `accordion-fidelity` importa el fixture y renderiza.
- `DEFINITION-OF-DONE.md` corregido (paso 8 = test verídico; paso 7 = organización por ejes; Colocación Model B).
- `Foundations/Corpus Status` muestra el estado por-paso; `census.json` al día.
- Suite completa (`vitest run`) + gobernanza (`npm run coverage`) verdes.

## Alignment

Ejecuta **design-system-quality (ADR-029)**:
- **Pilar 2 (listón de CALIDAD por componente):** a11y AA (axe + teclado/foco/ARIA) + tests + el DoD **gateado** —
  no basta escribirlo, cada parte la fuerza un gate.
- **Pilar 4 (migración limpia y revisable, "las máquinas sudan, el humano juzga"):** el gate prueba lo mecánico
  (fidelidad/organización/clasificación), el **[H]** juzga y aprueba; `Migration/`→`Primitives/` es la promoción
  gateada; **medio-hecha NO es hecha**.
- Concreta el **"gate de completitud de pieza"** que la estrategia nombraba (`DEFINITION-OF-DONE.md`, "Completitud").
- La fidelidad viejo-vs-nuevo (fixture + render + `old = new`) es la verificación verídica de que la migración
  preservó las características de la pieza.
