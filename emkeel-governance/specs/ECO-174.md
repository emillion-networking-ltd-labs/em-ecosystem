# ECO-174 — SegmentedControl: convertir en compuesto que reusa Button

Strategy: design-system-quality

## Contexto

SegmentedControl re-implementaba a mano el estilo de los botones (clases adaptadas: `shadow-xs`, tokens
propios) → aparecía como "leaf" en el censo aunque VISUALMENTE es un grupo de botones. La idea del DS es
**reutilizar el primitivo por propagación**: si Button cambia, el compuesto cambia solo.

## Alcance

- `SegmentedControl.tsx` → **compuesto**: cada segmento es un `<Button>` REAL.
  - Activo = `<Button variant={variant}>` (primary/secondary/outline).
  - Inactivo = `<Button variant="ghost">` (la variante añadida en ECO-173).
  - `size` se propaga a Button (default `sm`, patrón de control compacto como IconButton); `fullWidth={false}`.
- **Lo ÚNICO escrito es el contenedor** (propio y único de la pieza): `bg-surface-subtle rounded-lg border p-1`
  + `gap-1` (respiro uniforme = el mismo 4px que el `p-1` deja alrededor). Cero clases de botón manuales.
- `segmentedControlSpecs` refleja la composición (no clases re-implementadas). ComponentShowcase intacto.
- Registry: SegmentedControl pasa a `registryDependencies: [Button]` → **compuesto** en el censo.
- Se retira `segmentedcontrol-fidelity.test.tsx` (era la guarda de la migración tv, ya cerrada; el compuesto es
  un cambio VISUAL deliberado, no fidelidad).

## No-goals / nota de cambio visual

- **Es un cambio visual a propósito** (toma las características REALES de Button): el activo pierde el `shadow-xs`
  adaptado y gana el `hover:opacity-90` de Button; el inactivo (ghost) gana `hover:bg-surface-subtle`.

## Acceptance Criteria

- SegmentedControl no define clases de botón — las propaga de `<Button>`; solo escribe su contenedor.
- `registryDependencies` incluye `Button`; dashboard re-pulla el cierre (SegmentedControl + Button) sin drift.
- coverage + story-norm + vitest + dashboard tsc verdes. API pública (`variant`/`size`/`options`/`value`) intacta.

## Alignment

- **Pilar 1 (construcción) + reuso de primitivos:** el compuesto REUSA Button por composición (single source),
  no re-implementa. Lo único propio (el contenedor del grupo) se escribe; todo lo demás se propaga.
- **Reabrir el primitivo (memoria del operador):** para lograrlo se añadió `ghost` a Button (ECO-173) — se
  enriquece el primitivo, no se adapta en el compuesto.
