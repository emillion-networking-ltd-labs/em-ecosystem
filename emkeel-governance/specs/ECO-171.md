# ECO-171 — Tabs: migración al contrato de variante (tailwind-variants)

Strategy: design-system-quality

## Contexto

Cuarta pieza de la migración (censo ECO-167), **carril de juicio** — la más compleja hasta ahora. Tabs es
raw-concat con **DOS superficies** (el `tablist` contenedor + cada item) y lógica muy condicional: variante
(subtle/nav/nav-horizontal), tamaño (subtle only), estado active/inactive, `fullWidth`, `wrap`, y el branching
`isNav` que cambia por completo el layout del item.

## Alcance

- `Tabs.tsx` → dos contratos `tv` (`tabsContainer` + `tabsItem`, `twMerge:false`) construidos desde los MISMOS
  consts (`variantStyles` + `sizeClasses`). El branching subtle/nav, active/inactive y size(subtle) se modelan
  con `compoundVariants`. El `border-r` entre items es POSICIONAL → se pasa por `className` en el render.
- **Migración interna pura**: `variantStyles` (lo consume SidebarNav: `variantStyles.nav.inactive`) y `tabsSpecs`
  (lo consume ComponentShowcase) se **conservan** exportados → sin cambios en consumidores.
- **Sanea un token basura**: el viejo volcaba una clase literal `"false"` en el contenedor nav/nav-horizontal
  (`${!isNav && "…"}` → `false && "…"` = `false`). Inerte (ningún CSS la matchea) — el tv la elimina.
- Registry regenerado (dep `tailwind-variants`); dashboard + satélite re-pullan sin drift.
- Stories: headers de cajón (Variantes + AllVariants); `subtle` se documenta en SegmentedControl, sin AllSizes.

## No-goals

- **Sin cambio visual** (fidelidad exigida). Colores/tokens/calidad = otra lente/fase.

## Acceptance Criteria

- Tabs usa `tv` (contenedor + item); API (`variant`/`size`/`fullWidth`/`wrap`/`renderTab`…) intacta;
  `variantStyles` y `tabsSpecs` siguen exportados (consumidores sin tocar).
- Fidelidad: las 36 combinaciones (3 variantes × 3 tamaños × fullWidth × wrap) producen el MISMO conjunto de
  clases del contenedor Y de los 3 items — incluyendo active/inactive y el `border-r` posicional
  (`tests/tabs-fidelity.test.tsx`; el token inerte `"false"` se filtra por ser no-clase). Se retira al cerrar.
- Registry anti-drift verde con la dep `tailwind-variants`; dashboard + satélite re-pullan.
- coverage (variant-coverage, story-norm, drift…) + vitest + dashboard tsc verdes.

## Alignment

- **Pilar 1 (construcción):** migra Tabs al CONTRATO ÚNICO (`tv`), incluso una pieza de dos superficies con
  branching — con `compoundVariants`, sin escaparse del contrato.
- **Pilar 4 (migración limpia):** censo-driven, tabla de fidelidad exhaustiva por pieza, sin cambio visual;
  además SANEA un token basura latente sin parchear alrededor.
