# /handoff — compose a note for another window with PRECISION (the emitting pair of /intake)

You are COMPOSING, not executing: /handoff never creates tickets, branches or code — it produces ONE
copyable block the operator pastes into the destination window, where /intake receives it.

## The flow — two steps, always
1. **Invoked alone: ask.** What is being transmitted, and to which window/repo? If the material is
   already in this conversation, confirm which part.
2. **Compose the block** — short, because dose matters (more specification degrades; short and
   hierarchical wins):

   Nota <origen> → <destino> — <titulo corto>

   ## Asks
   1. <one ask, one line — the shortest sentence that carries the requirement>
   2. <next ask>

   ## Context
   <the rationale, evidence, history — everything that is NOT an ask, kept APART so the receiver's
   coverage stays clean>

## Hard lines
- One ask per numbered line; never bury an ask inside Context — an ask the receiver's decomposition
  cannot see is an ask that dies in transit.
- **Short is not abridged.** Dose matters, but compression is exactly where the operator's strongest
  argument gets dropped — the same incident /intake guards against (an agent composed a note from memory
  and dropped the load-bearing point; the gate went green against the abridgement). QUOTE the operator's
  actual words where they carry the requirement; never paraphrase a load-bearing detail away to make a
  line shorter. You are composing a note the operator will ACT on — fidelity beats brevity.
- The block must PASS the intake judge: numbered sequential asks, no tables, no loose prose between
  items (the same shape `emkeel agree new` refuses — the two ends of the channel are married by test).
- Show the finished block as plain text (never a syntax-highlighted box) and have the operator VERIFY
  COMPLETENESS — not just readability — before they copy it: you composed it, so an OMISSION is invisible
  to you, and only the operator remembers what you left out.
- Respond in the operator's language.
